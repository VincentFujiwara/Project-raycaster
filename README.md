# Project-raycaster

3D-рейкастер на чистом C (raylib) с элементами шутера от первого лица.
Проект написан с нуля без использования сторонних 3D-движков. Вся математика, рендер и физика реализованы вручную.


🚀 Особенности проекта

- Классический DDA-рейкастинг: Эффективный рендер 3D-сцен на основе 2D-карты. Поддержка текстур, освещения и теней.

- Свободное прицеливание (Arma-style): Камера и прицел разделены. Мышь двигает прицел внутри «мертвой зоны», а камера поворачивается только при достижении границ.

- Физика и стрельба:

- Реалистичная отдача оружия (подскок прицела).

- Спавн физических гильз (с отскоком от стен и пола).

- Оставление пулевых отверстий на стенах (с защитой от «стрельбы в небо»).

🎮 Интерфейс:

- HUD с отображением патронов, стамины и FPS.

- Мини-карта в реальном времени.

- Индикатор перезарядки и управления громкостью.

- Мультипоточность: Использование OpenMP для параллельного DDA-прохода (рендер в несколько потоков).

- Атмосфера: Красивое ночное небо с процедурными звездами и луной с кратерами.

🛠️ Технический стек

-Язык: C (стандарт C11)

-Графика: raylib (v5.5+)

- Многопоточность: OpenMP

- Сборка: MinGW-w64 (GCC)

- Среда разработки: Red Panda C++ / VS Code (по вкусу)

🛠️ Требования

- Компилятор с поддержкой C11 (GCC, Clang)

- Установленная библиотека raylib

- Поддержка OpenMP (опционально, но рекомендуется)

- Процессор минимум R5 3200g или I3 10100

🎮 Управление

Клавиша	Действие

W, A, S, D	- Движение

Мышь	- Свободное прицеливание

ЛКМ / Ctrl	- Стрельба

R -	Перезарядка

Пробел - Прыжок

Shift	- Бег (тратит стамину)

M	- Вкл/Выкл мини-карту

X / Ъ	- Уменьшить / Увеличить громкость
